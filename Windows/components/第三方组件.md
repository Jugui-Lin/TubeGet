# 第三方组件

命令行组件以独立的 Windows x64 进程运行，随 TubeGet 发布包提供。许可证与原发行说明位于各组件子目录。WebView2 的 SDK DLL 位于主程序同级目录，调用系统的 WebView2 Runtime。

| 组件 | 版本 | 发行与源码 |
| --- | --- | --- |
| yt-dlp | 2026.10.26 | [官方发行版](https://github.com/yt-dlp/yt-dlp/releases/tag/2026.10.26) · [对应源码](https://github.com/yt-dlp/yt-dlp/tree/2026.10.26) |
| FFmpeg 与 ffprobe | 9.0.2 Essentials，Gyan Windows 构建 | [原始二进制发行版](https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2) · [对应 FFmpeg 源码](https://github.com/FFmpeg/FFmpeg/commit/946fcce07b) · [构建与库说明](https://www.gyan.dev/ffmpeg/builds/) |
| aria2 | 1.37.0，Windows 64-bit build 1 | [官方发行版与源码](https://github.com/aria2/aria2/releases/tag/release-1.37.0) |
| Microsoft WebView2 SDK | 1.0.4314.35，Windows x64 | [NuGet 官方包](https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.4314.35) |
| QuickJS-NG | v0.18.0 | [官方发行版](https://github.com/quickjs-ng/quickjs/releases/tag/v0.18.0) · [对应源码](https://github.com/quickjs-ng/quickjs/tree/v0.18.0) |

随包提供的抖音解析扩展参考了 yt-dlp 的 [抖音 403 修复补丁](https://github.com/yt-dlp/yt-dlp/pull/17826)，与 yt-dlp 同用 Unlicense。
