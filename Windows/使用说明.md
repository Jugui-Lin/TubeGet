# TubeGet

在 64 位 Windows 10 或 11 上完整解压发布包，再双击 TubeGet.exe 启动。界面参考 Motrix 的任务工作区，沿用 Material You 配色。左侧切换下载、已完成和转换。页头提供主要操作，底栏显示输出目录和任务状态。点击左侧「输出目录」可打开对应文件夹。单击右上角的外观按钮可在浅色和深色之间即时切换。「设置 → 常规 → 外观模式」可选跟随系统。

## 下载

打开「下载中」，在下载工作台上方用默认的「自动识别」模式粘贴链接。左侧显示解析结果，右侧显示下载队列。单个作品在结果区显示标题、封面和画质选项，列表和频道显示可勾选的条目，多条链接直接进入批量列表。音轨、字幕和封面可在「附加选项」中设置。点「粘贴链接」会自动解析剪贴板里的链接。手动输入后可按 Ctrl+Enter 解析。输入框内的「清空」只清掉链接，左侧解析结果和右侧下载队列会保留。结果区右上角的「清空列表」保留输入链接。批量结果表头的复选框可全选或取消全选。需要仅解析单个作品或只下载字幕与封面时，可手动选择对应模式。

- 单个链接。粘贴作品链接并开始解析，然后选择画质或仅音频。画面与音频分轨时，可以指定音轨。解析结果显示站点返回的封面、分辨率、编码和文件大小。
- 列表解析。输入作者主页、频道、合集或播放列表，解析后勾选要加入队列的条目。合集与播放列表下载到保存目录下的同名子文件夹。Windows 不允许用于目录名的字符会被替换。
- 链接列表。粘贴多条链接或导入 TXT，确认列表后批量入队。支持设置画质上限和添加顺序编号。
- 字幕与封面。解析后选择人工或自动字幕语言、输出格式，以及是否同时保存封面。

在「下载工作台 → 登录选项」可以为本次解析和下载选择 Cookies 来源。选「自动读取 Edge」「自动读取 Chrome」或其他浏览器时，程序会读取该浏览器最近使用的配置文件。若数据库被占用或浏览器限制解密，可以先粘贴网站链接，点「去登录」，在应用内网页完成登录，再点「已登录，获取 Cookies」。之后选择「应用内站点登录」即可复用本站会话。站点 Cookies 由当前 Windows 用户加密保存在本机。也可以继续使用 Cookies 文件。在「参数设置 → 网络」可选择默认来源。

视频密码仅在程序本次运行中使用，关闭程序后需要重新输入。下载任务支持暂停、重试、重命名和加入转换队列。

B 站个人空间首页和投稿页会自动按投稿列表解析。若 B 站暂时限制列表请求，可稍后重试，或在下载工作台的「登录选项」获取 B 站的登录 Cookies。

抖音支持视频作品页、带作品编号的抖音精选链接、视频分享短链和含链接的分享文字。若抖音未提供播放信息，可先确认作品在抖音中能打开，再用「登录选项」获取抖音会话后重试。

新片场请使用作品页链接，例如 https://www.xinpianchang.com/a13870097。桌面页返回 403 时，内置解析器会自动尝试该作品的移动页。可选清晰度以站点实际提供的播放源为准。

## 转换

进入「转换」，导入或拖入媒体文件，选格式后点击「全部开始」。无损转换采用码流复制，要求源编码与目标容器兼容。转换任务右键可指定软字幕或硬压字幕。有视频画面的任务可右键选择「水印擦除」，在预览帧上圈选区域。转换及水印处理生成新文件。「转码参数」可设置 H.264、H.265、VP9 或 AV1、目标高度上限、码率、命名方式和输出目录。NVIDIA、Intel、AMD 硬件编码选项需要对应显卡与驱动。

点击「已完成」页工具栏最右侧的列表／网格图标，可在「列表视图」和「封面卡片」之间直接切换。已完成的合集会显示为文件夹，双击进入合集，里面也可用工具栏最右侧的按钮切换列表或封面卡片。合集内和「已完成」首页分别记住视图，点击「返回」回到上一级。合集卡片优先显示解析时取得的合集封面，也可以使用已保存的分集封面或从本地视频截取一帧。单个视频的卡片同样支持本地封面和视频截图。

## Behance 作品

粘贴 Behance 作品页链接并使用「自动识别」，TubeGet 会列出作品中的 Vimeo 或 YouTube 视频。遇到 Vimeo 播放器验证时，可先在浏览器打开作品，再用「登录选项」读取该浏览器的 Cookies。

## Vimeo 视频

公开的普通视频链接在解析器要求登录时会尝试对应的播放器。若播放器提示验证或拒绝访问，先在浏览器完成验证并确认作品可以播放，再在「登录选项」使用相同浏览器的 Cookies 重试。需要 Vimeo 登录时也可通过「应用内登录」保存登录会话。

## AI 链接修复

在「设置 → AI 修复」选择一个服务，测试成功后开启自动修复并保存。

- GPT（OpenAI API）或豆包（火山方舟 API）需要模型 ID 和 API Key。密钥由 Windows 当前用户加密存储。
- Codex（本机程序）调用已经通过 ChatGPT 登录的 Codex 命令行，使用 ChatGPT 账号额度，无需在 TubeGet 填 API Key。程序路径留空时自动查找，可选填模型 ID。
- Ollama（本地模型）调用本机 Ollama，请先启动 Ollama 并在其中准备好模型，再填写模型名称。程序路径留空时自动查找。
- 自定义本地程序可选择支持非交互运行的 EXE，按需填写 Windows 命令行参数。程序从标准输入读入 UTF-8 提示词，并将包含 action 和 issue 字段的单个 JSON 对象写到标准输出。豆包桌面客户端暂无内置命令行适配。

解析失败时，应用只传入站点类型和错误分类等诊断信息。链接、Cookies、代理凭据和原始日志留在本机。

模型可建议改为作品页、移除已知跟踪参数或重试。应用仅对经过本地校验的方案重新解析一次，解析成功后显示结果，仍需手动加入下载队列。登录过期、权限不足或解析器异常会显示对应提示。功能默认关闭。

## 单文件版

双击 TubeGet-Standalone.exe 即可启动。首次运行会把随包组件解包到当前用户的本机缓存，后续启动复用该缓存。单文件版与便携目录版共用现有设置和任务历史。应用内网站登录调用系统的 WebView2 Runtime。

## 组件与兼容性

程序从 TubeGet.exe 同级的 components 文件夹加载内置的 yt-dlp、FFmpeg、ffprobe、aria2 和 QuickJS。设置的「常规」页可查看和打开这个目录。移动或备份时请复制整个 TubeGet 文件夹。无需安装 CR TubeGet，也无需另装上述命令行组件。应用内站点登录使用系统的 Microsoft Edge WebView2 Runtime，加载库随包提供。组件版本、来源和许可证见 components/第三方组件.md。

「设置 → 组件」中的「检查并更新」会从 GitHub 安装 yt-dlp、FFmpeg 与 ffprobe、aria2 和 QuickJS-NG 的新版稳定版。开启「启动时自动更新组件」并确定后，每次启动会在后台检查。更新版本存放在 %LOCALAPPDATA%\TubeGetDesktop\component-updates，新任务优先使用可用的新版组件。下载或校验失败时继续使用已有版本。

设置与任务历史保存在 %LOCALAPPDATA%\TubeGetDesktop。升级会继续读取旧设置和任务历史。

站点覆盖以下载组件的解析器为准。原版的专用解析器、账号注册、支付和在线升级未接入。第三方站点的登录、地区限制及当前可下载性需用实际链接验证。

## 源码与验证

源码目录中的 build.ps1 使用 Windows 自带的 .NET Framework C# 编译器重新构建。使用本地 HTTP 服务验证了媒体格式解析、直链视频、音频提取、aria2 下载、HLS 与封面下载。还验证了 MKV 软字幕、MP4 硬字幕、WebM 与 MP3 转换、MOV 无损封装、水印区域处理及三个工作区的程序初始化。
